Eco Hub University Management System

Overview

This repository contains my MIT 8103 Advanced Database Systems portfolio, based on the ECO Hub University Management System, a fictional university campus energy-monitoring and sustainability scenario.

The portfolio demonstrates five database activities:

Database Design and Modelling: Relational database design, ER modelling, normalisation and integrity constraints using PostgreSQL.

Query Optimisation: SQL queries, indexing and query execution plan analysis.

Transactions and Concurrency: Transaction management, commit and rollback operations, and concurrent database access.

NoSQL and Advanced Data Models: MongoDB document modelling, embedding, referencing, queries, aggregation and validation.

Distributed and Cloud Databases: PostgreSQL logical replication using a publisher-subscriber architecture.
